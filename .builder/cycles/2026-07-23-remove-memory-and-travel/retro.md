# Retro

Belief: the product becomes clearer when it owns one emotional job instead of competing with maps and journaling.

Learning: a clean feature retirement must include executable code, generated deployment artifacts, live cloud resources, secrets/configuration, marketing demos, design prototypes, QA evidence, permissions, terminology, and future-agent plans—not only visible app entry points.

Decision: close this removal cycle. BeforeShow now owns the current-show countdown; any reintroduction of song, travel, or memory tooling requires a new product cycle.
