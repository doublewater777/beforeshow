# Retro

## Belief

A small, phase-aware entry can carry the whole one-friend companion lifecycle without growing Current into a social feed.

## Learning

The supplied state model fits the existing quick-action architecture. System share presentation must be treated as a separate effect after persistence, not as the owner of the invitation state transition.

## Decision

Complete this implementation cycle and validate the manual-confirmation wording with real users. If users require remote acceptance, start a separate account/deep-link cycle rather than extending this local model implicitly.
