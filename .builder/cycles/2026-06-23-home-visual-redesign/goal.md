# Home Visual Redesign Goal

Feature: BeforeShow iOS home visual redesign and current-show flow polish.

Linked stage: `.builder/stages/09-business-model.md`

Target user: BeforeShow V2.1 users with a real upcoming or recently ended concert, Livehouse show, or music festival.

User problem: the current home screen exposes the right tools but feels more like a dashboard than a theatrical companion for entering the show mood.

Desired behavior change: users recognize the current show immediately, pick one of two core next actions, and use expandable tools only when they need the broader loop.

Success criteria:

- Home removes the large status heading and keeps "当前现场" as the quiet caption.
- Home uses a single poster-led layout.
- Current show auto-selection keeps a post-show inside the 3-day retention window, then switches to the next nearest show; if none remains, the ended show stays with a next-show prompt.
- My Shows highlights the current show with a gradient border and no separate current label.

Out of scope:

- New AI generation behavior.
- Account sync.
- New pricing tiers.
- Public social features.
