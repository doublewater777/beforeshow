# Home Visual Redesign Assumptions

## Must Be True

- A theatrical, poster-led home screen increases emotional clarity without hiding practical actions.
- Two primary entries are enough for most current-show states; the rest can live behind an expandable section.
- A single poster-led layout keeps the mood consistent without fragmenting the main product loop.
- Removing artist text under the title reduces clutter while still letting music festivals show lineup context.

## Falsifiers

- Users cannot find secondary tools after the expandable section replaces the old direct row.
- (Style selection removed; no longer a concern.)
- Music festival users need interactive lineup planning directly on home rather than a read-only row.
- The ended-show state feels too empty after removing feeling/recap-style entries.

## Existing Evidence

- HTML prototypes in `apps/ios/design-exploration/` explored half-cover, cross-day, ended, settings, and all-tools states.
- The active V2.1 core loop already proved local tool screens and Pro gating are implemented.
