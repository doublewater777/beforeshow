# Global Transit ETA Retro

Belief: a saved ETA plus Apple Maps handoff is sufficient for the first globally available public-transit experience.

Learning: MapKit's transit ETA and Apple Maps handoff cover the planned technical flow without inventing route details. Transit timing must preserve the user's arrival/departure intent because schedules are time-dependent. Product usefulness still needs user validation.

Decision: implementation and simulator verification are complete. Continue the cycle through user validation; keep multi-provider transit routing as a loop-back option rather than current scope.
