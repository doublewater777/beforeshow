# Pro Membership Experiments

Initial validation should test whether users accept Pro gates after experiencing one useful preparation loop.

Measure:

- Free-to-Pro upgrade intent or purchase.
- Candidate song generation attempts after free allowance.
- Round-trip draft generation attempts after free allowance.
- Number of real shows saved per user.
- Paid user return behavior before and after a show.

Pass threshold is not set yet. The packaging to test is one free saved show plus a one-time AI first-experience package, followed by Pro at ¥12/month or ¥68/year.
