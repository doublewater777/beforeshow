# Retro

## Belief

A private capture flow can add emotional value without reopening the retired social, history, cloud, or AI scope.

## Learning

The three-card Current layout remains legible on iPhone 17. The global floating tab bar also remains visible on pushed Current destinations, so a destination's fixed action must reserve that overlay explicitly. Real interaction caught both that overlap and a navigation state reset that compile/tests alone did not expose; the stable solution is a direct NavigationLink owned by the existing NavigationStack.

Ordered PhotosPicker selection works for a mixed video/photo group, and staging is necessary because picker and camera return values are not durable storage contracts.

## Decision
