# Current-show Memory Fragments

## User problem

A live-goer has small private moments around the current show—one sentence, a photo, or a video—but BeforeShow currently has nowhere lightweight to keep them with that show.

## Target user and behavior change

The target is an individual BeforeShow user attending one current show. After this increment, they should be able to open one stable shortcut, capture text or media with low friction, and return later to a private chronological record tied to that show.

## Success

- Current keeps Route and Companion unchanged and adds Memory Fragments as the third equal-width shortcut in one row.
- A user can save text, one or more photos, one or more videos, or a mixed ordered group with one shared caption.
- Saved content remains local, survives relaunch, and never appears under another show.
- The full iOS suite passes and iPhone 17 screenshots cover the changed Current surface and memory flow.

## Out of scope

History/Footprints integration, sharing, export, backup, cloud sync, accounts, social interactions, search, tickets, audio, AI, and a custom camera.
