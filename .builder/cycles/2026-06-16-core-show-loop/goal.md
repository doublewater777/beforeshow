# Core Show Loop Goal

User problem: live-goers save a show but still need one calm place to decide what to listen to, how to get there and back, what to prepare, what to preview, and what to remember afterward.

Target user: BeforeShow V2.1 TestFlight users with one real upcoming concert, Livehouse show, or music festival.

Desired behavior change: after saving one show, the user can move through the five core features without leaving the app structure or losing local edits.

Success:

- Tonight First Listen generates and displays candidate songs once for free, then gates repeated generation behind Pro.
- Round-trip plan generates editable outbound and return drafts from show/place details, then saves local edits.
- Preview Before Show shows artist, venue/seat, entry, weather/traffic guidance, then saves only lightweight public Bilibili metadata and opens official external playback/original pages.
- Show preparation is a persistent checklist with reminder time and private notes.
- Show fragments save local text, gallery references, and app-created audio without an account.
- StoreKit Pro purchase/restore unlocks limits.

Out of scope:

- Account sync.
- Ticket screenshot upload.
- Lyrics display.
- Bilibili media caching.
- Social/community features.
