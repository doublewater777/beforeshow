这版改了什么

  • 入口页从「列表」变「引导」：现状三张方式卡只有标题 + 一句副文，新用户不知道选哪个。V1 给链接解析加「推荐」徽章（转化最高、失败率最低），每张卡加预期胶囊（约 10 秒 / 设备端不上传 / 约 1 分钟），底部一行隐私承诺。标题从「添加现场」改为面向场景的「把下一场现场放进来」。
  • 入口接入 sheet 导航语言：现状入口页是 ScrollView 顶部一个左对齐「取消」文字按钮，与编辑现场的 sheet 样式不一致。V1 统一为 grabber + 居中标题 + 左侧取消的 sheet-nav，与编辑现场 V1 对齐。
  • 链接来源即时识别：现状粘贴后要点「开始解析」才知道支持不支持。V1 在输入框失焦 / 粘贴时就识别域名，显示「✓ 大麦」chip，不支持时立刻给提示，不用等一次失败往返。
  • 解析中给预期：现状只有按钮里一个 spinner。V1 按钮文案变「正在解析…」+ 下方 note 说明「通常 10 秒内完成，失败也能转手动，内容保留」，把等待和失败焦虑都提前消化。
  • 失败可行动化：现状失败是一个 BSEmptyPanel + 单个「手动填写」按钮。V1 升级为珊瑚色失败卡：图标 + 原因标题 + 说明 + 「换个链接重试 / 转手动填写」双按钮，并明示「已填写的内容会保留」。转手动后表单顶部带来源胶囊「手动填写」，开场时间瓷贴金色标出唯一缺口。
  • 截图识别分步可见：现状识别中是一个 dashed 框里的小 spinner + 一个 loading panel，用户不知道要等多久、卡在哪。V1 把识别拆成四步（读取截图 → 提取文字 → 整理现场信息 → 生成草稿），完成打勾、进行中转圈、附带耗时；隐私说明从底部小字升级为卡片胶囊「设备端 · 不上传」，并补充「不读取座位、价格、订单号」。
  • 确认页「已识别 / 待补」双色标：现状识别成功后表单和手动填写长得一模一样，用户不知道哪些要核对。V1 加薄荷绿横幅「已识别 4 项信息」，识别出的字段薄荷绿描边 + 「✓ 已识别」标注；缺的必填项（开场时间）金色瓷贴 + 按常见值预填 19:30 待确认。确认页标题从「截图识别」改为「确认现场信息」，呼应 UX plan 08「禁止静默直接保存」。
  • 保存栏进度阶梯：现状保存栏状态文案已经存在（还差名称 → 还差开场时间 → 可以保存了），V1 在其上方加两段式进度条（名称/时间），把「还差什么」从文字变成可视进度；可保存时进度条转薄荷绿。
  • 成功反馈落到「进入状态」：现状保存成功直接 dismiss，没有反馈。V1 按 UX plan 08 加 toast「已放入当前现场，倒计时开始」，明确下一步是首页倒计时，且不自动弹 Pro。
  • 封面不挡路：手动 / 确认流程里封面卡标注「可选 · 保存后也能加」，空态是虚线引导框而非必填项；识别带来封面时沿用编辑现场 V1 的模糊底 + 3:4 海报预览，badge 标注「来自截图」。
  • 不变的：三种入口与 coordinator 状态机、大麦/秀动支持范围、设备端 OCR、saveBarStatus 优先级逻辑、确认页必达（链接/OCR 不静默保存）、通知权限在保存后请求——全部沿用现有实现，本原型只做信息架构与视觉层的优化。
