这版改了什么

  • 顶部摘要常驻：现状编辑页滚两步就忘了在改哪一场。V1 加 58pt 封面缩略 + 名称 + 原定日期 + 状态胶囊的摘要卡，滚动时提供上下文锚点。
  • 保存栏固定在底部：现状「保存」按钮埋在表单最底，长表单要滚到底才能存。V1 改为吸底毛玻璃保存栏，任何滚动位置都能保存。
  • 未保存状态显形：保存栏上方有金点提示「有未保存的修改」，与现有 hasUnsavedChanges / 放弃修改确认逻辑对齐，用户不再靠猜。
  • 分组卡片化：现状 FieldGroup 是纯文字标题 + 平铺输入框。V1 每组收进圆角卡片并配金色/紫色/薄荷绿图标，层级扫一眼就分清。
  • 日期时间瓷贴：开场日期 / 开场时间并排两张瓷贴，「记录散场时间」收成开关，展开后再给散场日期 + 时间瓷贴；多日场（音乐节）的结束日期不再突兀。
  • 校验前置：散场早于开场时，错误文案就地标红 + 散场瓷贴描红边，保存按钮变灰并在保存栏说明原因——不再等点保存才报错。
  • 延期横幅：延期现场的提示原本是标题下一行小灰字。V1 升级为紫金渐变横幅，说清「这里改的是原定信息，延期日期在下方现场状态卡更新」，日期瓷贴标注「原定」。
  • 封面卡合并 + 3:4 海报：现状「当前封面」和「更换封面」是两个分离分组，且预览用 16:10 把 3:4 海报拦腰裁掉。V1 合成一张封面卡：模糊底 + 居中 3:4 海报（不裁切）+ 相册 / 链接两个入口；摘要缩略图同为 3:4。
  • 现场状态并入编辑现场：延期 / 取消 / 恢复 / 删除原本散在详情页底部的「现场状态」分组，和信息编辑是两个入口。V1 把状态管理收进编辑 sheet 底部的「现场状态」卡：状态胶囊 + 说明 + 「恢复」整行中性按钮 + 「延期 / 取消」并排紫金 / 珊瑚双色按钮，「删除现场」为卡外文字入口。状态操作立即生效（沿用 mark* 语义与 toast 反馈），详情页只留 hero 上的状态展示。
  • 保存成功反馈：toast「已保存，首页已更新」呼应首页海报与倒计时的即时刷新。
  • 不变的：Stage 色板、字段集合、必填规则、endDate/endTime 数据模型、放弃修改确认弹窗全部沿用现有实现。
