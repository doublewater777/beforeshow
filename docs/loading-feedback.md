# 加载反馈

BeforeShow 尽量不使用可见的加载文案。等待中的变化由进度图标或骨架屏表达，文字留给动作和用户需要判断的结果。

## 规则

- 页面、弹层和局部内容的纯等待状态只显示进度图标或骨架屏，不显示「加载中」「正在载入」等文字。
- 按钮执行动作时保留原本的动作名，增加进度图标并禁用按钮；不把动作名改写为「正在解析」「正在保存」等过程文案。
- 「连接中」及授权请求中的短暂过渡按加载状态处理，只显示进度图标或骨架屏。
- 生成、导出、准备视频等由用户直接触发的阻塞操作也只显示进度图标；如果能获得真实进度，则改用进度条或百分比，不添加泛化的过程文案。
- 「完整播放」「试听模式」「未授权」「连接失败」等可停留、需要用户判断的结果状态保留文字。
- 可见文字被移除后，加载状态仍需提供准确的 VoiceOver 描述。

## 呈现顺序

1. 后台刷新已有内容时，保留内容，在刷新入口附近显示小型进度图标。
2. 首次加载且内容结构明确时，显示骨架屏。
3. 没有可预示的内容结构时，显示 `ProgressView`。
4. 有真实进度时，显示进度条或百分比。

不足 300ms 的快速任务不显示加载反馈；加载反馈出现后不人为延长显示时间。

## 文字边界

- 保留动作名、真实阶段名、成功、失败、空状态及需要用户操作的说明。
- 删除「加载中」「载入中」「连接中」「生成中」「正在准备」「正在解析」「正在保存」等只表达等待的可见文字。
- 多阶段任务只有在阶段名能帮助用户理解真实进度时才显示阶段名。

## 实施范围

- 添加现场：链接解析、保存、艺人搜索与封面获取。
- 当前现场：动态封面准备、同行邀请、分享生成与资料上传。
- 足迹：回忆卡片生成、保存与导出。
- 听：Apple Music 连接、唱片与曲目载入、艺人匹配。
- 设置与隐私：远程动作、数据统计与清理。
- Pro：商品载入、购买与恢复。
- 通用媒体：封面、动态封面及附件读取。

## 验收

- 全 App 不再显示泛化的加载文案。
- 加载中的按钮保持原动作名、显示进度图标且不可重复触发。
- 后台刷新不移除已有内容。
- 成功、失败、空状态和可操作说明未被误删。
- 所有纯图标加载状态都具有准确的 VoiceOver 描述。
