# BeforeShow「听」MVP 简报

日期：2026-09-05
用途：交给实现者自由发挥。只定义「有什么」和「不能违反什么」，不定义 UI 长什么样。

## 有什么

- 底部第三个 Tab「听」。
- Onboarding 加一步「听」（放在「开场前」之后）：让用户知道这个 App 能提前熟悉演出的歌。
- 主页面：顶部一行演出名、CD 机、「想现场听」按钮、唱片柜。
- 点唱片可以查看唱片详情。
- 艺人详情：仅听此艺人 / 排除此艺人 / 重新匹配（多艺人、音乐节场景用）。
- 空状态与异常态：无演出、未授权 Apple Music、未匹配艺人、加载中、缓存失败、完全不可用。

## 不能违反

1. CD 是多轨容器，歌是碟里的 Track。
2. 播放能力分 full / preview / metadata / unavailable；preview 永远不计入熟悉度。
3. 完整播放超 50% 自动记「已熟悉」；没有手动「听过」按钮。
4. 「想现场听」任何阶段都可以切换，不冻结。
5. 换碟要经过开盖、释放、取出、装入、合盖；自动装碟走同一条链，不跳步。
6. 同一张碟内自动续播；最后一轨播完停止，不自动换碟。
7. 不做歌词、排行榜、XP、随机/循环、播放列表、专辑分类。

## 已有基础

引擎层已完成并合并（Phase 1–5）：目录拉取、预热队列、播放、熟悉度证据。实现只需做 UI 和接线。

顺手收尾：退役原生 WantsLivePolicy / wantsLiveFrozen 及其测试（想现场听不再冻结）。
