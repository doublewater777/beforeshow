# Reintroduce song guessing as show-bound blind listening

BeforeShow reintroduces song guessing only as single-player Blind Listening inside Artist Warm-up for the current show, superseding ADR 0023 for this narrow scope. It uses user-initiated full-song Apple Music playback for subscribers, never previews or clipped audio, and remains a five-question secondary experience whose correct/incorrect results do not change artist familiarity; setlist guessing, multiplayer competition, rankings, and a standalone game center remain retired.
