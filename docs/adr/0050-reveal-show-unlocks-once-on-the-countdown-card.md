# Reveal what a show unlocked once, inside the countdown card

2026-11-08 产品决定：散场后，这场解锁的数字唱片和徽章在首页倒计时卡里原地揭晓一次，不做主按钮、不弹窗。

- 时机：现场进入散场后停留期、首页真正可见（没有 sheet / 仪式盖着）时。每场只揭晓一次（`home.unlockReveal.shownShowIDs`），本次停留在首页期间保留，下次进入不再出现。
- 内容：这场对应的第 N 张数字唱片；以及「算上这场」比「不算这场」升了档的徽章。只比较这一场带来的变化，所以老用户第一次看到时不会冒出一堆旧徽章。没有任何解锁就什么都不出现。
- 位置：现场名与主按钮之间，「刚解锁」一行；唱片转入，徽章随后淡入，一次成功触感。
- 点唱片去唱片墙，点徽章去徽章墙；徽章墙照常把新徽章掉落一次。

## Considered Options

- 做成散场后的主按钮。否决：主按钮是要用户去做的事（ADR 0049），解锁是已经得到的结果。
- 弹出解锁 sheet。否决：散场后已有散场仪式，再叠一层违反「一次只看到一个主界面」。
- 用已看过的徽章档位做基准。否决：从没打开过徽章墙的老用户会一次看到全部历史徽章。
