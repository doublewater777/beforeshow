# Listening disc pick from cabinet

## 决定

- 「听」唱片柜顶部提供「帮我挑一张」：从**当前浏览范围**抽出一张现场唱片封套，确认后经现有「装入播放机」路径装入并开播。
- 单位是唱片，不是单曲。`.all` 的候选为现场预习合辑与所有已连接艺人碟；`.artist` 只含该艺人。
- 挑选采用随机抽取，不再按热歌、熟悉度或稳定哈希固定排序；同轮内不重复，抽完后开始新一轮，并在有其他候选时避开上一张。沿用现有短历史存储格式，只避开上一张以减少重新打开时的重复，避免短历史把小候选池锁成固定循环；不改变每日 featured 头碟，不改听歌提醒队列。
- 挑片卡只展示专辑封面，不展示露出的 CD；前后卡片共用固定尺寸，标题和艺人区预留高度，避免内容变化导致卡片高度跳动。
- 卡片左滑回到上一张，右滑或「换一张」前进；会话内保留浏览历史，返回后再次前进沿用已看过的顺序，到历史末尾再随机抽新唱片。到达历史起点时仍可左滑，随机补一张到历史前方；之后右滑可返回原来的第一张。关闭后清空浏览历史。
- 右上角原生筛选菜单提供「全部 / 专辑 / 单曲和 EP」；切换后清空当前浏览历史并从筛选范围重新抽取，空结果仍可原位切换筛选。「全部」保留现场预习和歌单；类型筛选只匹配艺人发行，单曲依据目录 `isSingle`，EP 依据目录标题的 ` - EP`（含长短破折号）后缀，不按曲目数猜测。
- 播放只走 `ListeningRoomCoordinator.loadPlayableDisc`，遵守 ADR 0040；不开启 MusicKit shuffle。

## 明确不是

- 不是 Blind Listening / 猜歌（ADR 0032）。
- 不是提醒队列或通知推荐（ADR 0045 / 0037）。
- 随机只作用于挑选唱片，不改变唱片内曲目顺序，不新增推荐流或歌单产品面。
