# Live capture stays primary throughout the show

2026-10-01 产品复核后更新：现场中的主操作在整段现场里都是「记一段记忆」，打开新增记忆（相机 / 图库 / 文字）。「结束现场」一直放在快捷区；超过预计结束且未确认时，主操作变为「确认已结束」。多日现场的后续场次同样保留记忆主操作。

原先的一小时分界没有对应用户任务的变化；用户可能在演出后半段或音乐节后续场次更想记录。结束入口的可发现性由快捷区保证，主操作按现场是否结束决定。

开场时刻仍只发一条安静的开场记忆通知，点进去打开新增记忆。它与散场次日回看同属落到记忆的触点；开场后添加不补发，已确认结束不发送。

## Considered Options

- 开场一小时后把主操作切回结束现场。否决：经过一小时不意味着用户准备散场。
- 新增一个接近散场的固定时间阈值。否决：演出时长和音乐节节奏不同；沿用预计结束边界足够。
- 音乐节每天发送记忆通知。否决：一场现场只用第一次开场时刻，后续场次只保留页面入口。
- 把开场记忆通知做成 time-sensitive，或写成只叫拍照。否决：保持安静，不把记忆碎片收成相机。
