# Retire song guessing and travel planning; keep memory fragments

On 2026-07-23, BeforeShow removed song/setlist guessing and travel planning from the product. Their entry points, local models, generation/edit flows, notification destinations, Pro entitlements, cloud generation backend, tests, marketing demos, UX plans, and prototype assets are retired.

Memory fragments remain part of BeforeShow: users can create, edit, review, and share local memories associated with a show. Their local models, media services, permissions, tests, and product language remain active.

The deleted song-guessing and travel-planning ADRs and UX plans no longer describe the product. Reintroducing either retired feature requires a new product decision and implementation cycle.
