# Retire song guessing, travel planning, and memory fragments

On 2026-07-23, BeforeShow removed song/setlist guessing, travel planning, and memory fragments from the product. Their entry points, local models, generation/edit/share flows, media services, notification destinations, Pro entitlements, permissions, cloud generation backend, tests, marketing demos, UX plans, and prototype assets are retired.

The deleted feature ADRs and UX plans no longer describe the product. Reintroducing any retired feature requires a new product decision and implementation cycle.
