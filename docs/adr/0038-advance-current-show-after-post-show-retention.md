# Advance the current show after post-show retention

2026-10-01 产品决定：

- 当前现场已结束并过了散场后停留期（3 天），且有未来现场时，自动接到开场最近的未来现场。当前现场还没结束时，时间流逝仍不改变用户的选择；没有未来现场时保留原当前现场。
- 过了预计散场时间、到之后第一个 09:00（现场时区）仍未确认结束的现场，自动按预计散场时间记为结束；首页不再追问「这场已经结束了吗？」，用户仍可在现场详情修改散场时间。没去成的现场也会因此进入足迹，可在现场详情删除。

此决定修改听 Spec v1.1 §1.2：「当前现场结束超过 3 天」不再属于不得自动改变当前现场的事件。

## Considered Options

- 时间流逝永不改变当前现场（听 Spec v1.1 §1.2 原规则）。否决：看完一场后，首页、小组件和听停在旧现场，下一场的倒计时接不上。
- 散场后立刻切到下一场。否决：停留期用于散场仪式和记忆收尾。
- 一直等用户确认散场。否决：一周后还问「结束了吗」是负担。
