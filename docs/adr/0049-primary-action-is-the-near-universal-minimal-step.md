# Countdown card primary action is the near-universal minimal step

2026-11-08 产品决定：倒计时信息卡的主按钮只放这一刻几乎每个人都会做、一下就完成的事。没有这样的事就不放按钮。

| 阶段 | 主按钮 |
|---|---|
| 开场前（当天之前，含有新日期的延期） | 听几首：直接开始播放「今天这张」 |
| 当天、未开场（音乐节每天同样） | 看路线 |
| 现场中、音乐节当日落幕 | 不放 |
| 散场后停留期 | 听今晚的歌：直接播放这场没标「没唱」的歌单；没有歌单时听几首 |
| 停留期后 | 没有下一场时添加下一场；有下一场不放 |
| 时间待定 | 填上新时间：打开现场详情编辑 |
| 已取消 | 不放 |

听的按钮在播放中变为暂停，不换成别的动作；主按钮是路线时，快捷区不再重复路线。

取代 ADR 0033 的「现场中主操作是记一段记忆」和 ADR 0037 中倒计时信息卡推荐主操作的部分；通知推荐仍按 ADR 0037。

## Considered Options

- 主按钮轮换推荐没用过的功能。否决：每天换一个，用户记不住它是做什么的；小组件、同行这类不是这场现场此刻要做的事。
- 现场中放「记一段记忆」。否决：只有一部分人会记，现场中用户在看演出。
- 散场后放「记下感受」或解锁唱片、徽章。否决：前者要输入；后者是奖励，应作为一次性的原位反馈，而不是要用户去点的动作。
