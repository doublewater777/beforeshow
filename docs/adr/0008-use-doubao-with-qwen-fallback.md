# Use Doubao with Qwen as fallback

BeforeShow V2.1 will use Volcengine Doubao as the default model provider for AI generation, with Alibaba Qwen kept as a fallback option. Tencent Cloud remains the lightweight backend host, but model selection favors Chinese generation quality for candidate song ordering, round-trip drafts, and show video clues while keeping provider access behind backend-held credentials.
