# The countdown share card carries a code that adds the show

2026-11-12 产品决定：开场前在「当前」截图时，可以顺手分享一张倒计时分享卡，卡上印一个二维码，扫到的人能把这场现场直接加进自己的开场前。这是 #387「分享卡不放二维码、不放链接」的唯一例外；其他分享卡不变。

- 入口：开场前、有开场时间、「当前」真正在屏幕上（没有 sheet、详情页或别的 tab 盖着）时截图，右下角浮出一个「分享这场」气泡，5 秒后自己消失，避开系统截图缩略图所在的左下角。点气泡直接出图并调起系统分享面板，不经过预览页。首页不另放分享按钮。
- 卡面：首页同款舞台与海报、距开场天数（当天写「今天」）、开场时间、现场名、场馆，左下署名，右下二维码和「扫码添加这场」。
- 链接 `https://beforeshow.doublewaterapps.com/s/<token>`：token 是这场现场快照（名称、日期与开场/结束时间、时区、城市、场馆、封面地址）的 base64url JSON（`ShowShareLink`）。本机生成，不联网、不经过服务器，所以出图没有等待。延期后有新日期的现场按新日期写入，不带结束时间。
- 码要在聊天软件把卡片缩到三分之二后仍能扫，所以链接只带固定几项：艺人阵容不带（音乐节几十个名字会让码密到扫不出），对方导入后自己补；封面只带网络地址且不超过 200 字符，从相册导入的封面不随链接走。
- 扫码：装了 App 的直接打开预填好的添加现场（带来的字段标为已识别），保存才算添加，占免费容量；已经有这场只提示一次「这场已经在 BeforeShow 里了」；引导没走完就等引导结束。没装 App 的打开网页，看到这场现场和 App Store 入口；微信里引导到浏览器打开。
- 二维码用最低纠错等级、深色码点在象牙色底上：屏幕上的码不会破损，低纠错让码点更少。

## Considered Options

- 倒计时数字旁常驻一个分享按钮。否决：首页多一个控件；想分享的人本来就会截图，截图时接住就够了。
- 截图后直接弹分享面板。否决：每次截图都被打断。
- 服务器短链。否决：生成要联网等待（旧邀请链接就慢在这里），相册封面还要上传并公开托管，需要审核。
- 只在分享文案里放链接、图上不放码。否决：国内平台链接传播差（#388），图片才是唯一载体。
- 复用 `/join/<token>`。否决：那是旧同行邀请，会把分享者记成同行（ADR 0048）。

## Consequences

- 小红书可能把带二维码的笔记当作站外引流限流；发版前用测试号发一条确认。
- 微信里长按识别会停在微信内置浏览器，要么用相机扫，要么按页面引导去浏览器。
- AASA 新增 `/s/*`，要与带此功能的 App 版本同时上线；更早的版本被拉起后不认这条链接，停在首页。
- 链接是分享那一刻的快照，之后改时间不会更新已发出去的码。

2026-11-14 改了入口和卡面。截图不再触发分享，系统截图也替换不了。入口改到现场详情右上角的「分享这场」，开场前和开场中、有开场时间才出现；已散场、已取消、时间待定不出现。卡面去掉舞台和倒计时，改成海报原比例、开场时间、现场名、场馆、署名和二维码。海报只用本机已经保存的，没有就只留字和码，不等下载。现场名超过 200 字按同一上限截断，避免码能扫开却加不进去。二维码、链接内容和导入规则不变。
