# Keep an undated postponed show as the current show

When the current show is postponed without a new date, BeforeShow keeps it as the current show instead of automatically moving focus to another dated show. The Current and Warm-up tabs therefore remain aligned around the user's existing choice, allowing artist warm-up to continue while the new date is unknown; no opening-time familiarity snapshot or date-based warm-up reminder is created until a new date exists.
