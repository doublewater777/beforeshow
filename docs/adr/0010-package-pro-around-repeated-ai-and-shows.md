# Package Pro around repeated AI and saved shows

BeforeShow V2.1 will package Pro as an App Store subscription that unlocks repeated AI generation and unlimited saved shows, while keeping the first show useful for free users. Free users can save one show and receive one device-local first-experience package for candidate songs, outbound draft, return draft, and show recap; show fragments, show preparation, tonight's song, and manual edits remain free because charging for them would weaken the private emotional core.

Departure transport options are not part of the repeated AI generation gate in their first version because route facts come from a map provider and the saved departure plan is part of the show-day safety experience. Future Pro packaging may add premium route refreshes or preference memory, but the basic ability to generate and save one departure plan should remain outside the initial Pro wall.
