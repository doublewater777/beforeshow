# 时刻表统一采用舞台矩阵直编与检视抽屉交互

时刻表废弃独立的表单长列表校对页，OCR 识别后直接进入「舞台矩阵」作为查阅与纠错的唯一主界面；卡片右上角心形专职秒切「想看」，点击卡片主体弹出紧凑「演出检视抽屉」完成试听、跨舞台切换、时间微调与删除，原图对照以等比无裁切画中画常驻顶栏并支持全屏缩放。

## Context

原本时刻表在 OCR 识别后强制进入全屏表单长列表 (`TimetableReviewView`)，修改演出只能在列表内展开 inline 控件，且无法直观跨舞台移动；矩阵卡片点击默认直接切想看，导致用户无法查看艺人试听或在现场纠错；原图浮窗因强制填充导致边缘信息被截断。

## Decision

1. **废弃独立校对列表**：识别后直接呈现所见即所得的舞台矩阵画布；点击舞台空白时间槽即可新增现场，舞台名点击即可原地重命名。
2. **卡片点击双态分流 (Coachella 模式)**：右上角心形作为独立点击热区秒切「想看」；点击卡片主体呼出 40% 紧凑「演出检视抽屉」，支持直接点击药丸标签更换所属舞台、`±10m` 快捷步进调校时间与试听。
3. **等比无裁切原图画中画**：右上角常驻原图按钮替代原横屏切换；小浮窗采用 Aspect Fit 完整显示，点击平滑放大至全屏双指捏合缩放。
4. **非阻塞撞场高亮**：在矩阵中标记想看时，若存在时间重叠，通过卡片高亮与撞场徽标直观展现，不弹阻塞弹窗。

## Consequences

- 纠错链路从“列表表单逐项点开”变为“直视矩阵、点哪里改哪里”，大幅降低 OCR 误差修正的操作摩擦。
- 保证单一主表面 (Single Main Surface)，不再在列表页与矩阵页之间来回跳转。
- 保留了现场单手点心标记想看的速度，同时解锁了艺人试听与快速微调能力。
