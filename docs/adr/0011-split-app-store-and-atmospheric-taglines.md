# Split App Store and atmospheric taglines

BeforeShow will use "开场之前，先进入状态" as the App Store subtitle because it explains the product's pre-show use case immediately. Brand surfaces such as the splash screen, website hero, promotional visuals, and Xiaohongshu titles may use "灯亮之前，先进入状态" because it carries the stage, darkness, waiting, and prelude atmosphere more strongly.
