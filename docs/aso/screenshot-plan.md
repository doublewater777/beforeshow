## 10-slot 目标（前 7 张沿用现稿）

```
Slot 1: 下一场，正在靠近
- Screen: 首页今日开场 + 大海报 + 倒计时
- Layout: 暗底，短句在上，真机在下
- Key: 让搜「演唱会倒计时」的人 1 秒对上号

Slot 2: 到了现场，才刚刚开始
- Screen: 现场态首页
- Key: 不是日历 App，是「这一场正在发生」

Slot 3: 散场以后，把它留下
- Screen: 散场评分
- Key: After 只有轻轻一下，不是统计后台

Slot 4: 一个链接，就把现场收进来
- Screen: 添加现场三入口
- Key: 低负担

Slot 5: 把这一刻留下来
- Screen: 记忆碎片时间线
- Key: 私人，不是社交 feed

Slot 6: 每一场，都成为足迹
- Screen: 足迹列表
- Key: 证明能留下，但不要做成第一张

Slot 7: 散场，不代表结束
- Screen: 分享卡
- Key: 可被拿出 App 的物件

Slot 8: 桌面上也看得见下一场   ← 未拍
- Screen: 主屏小组件（docs/design/widget/preview-near.png 可作底）
- Key: 对上「倒计时小组件」预期

Slot 9: 灯亮之前，先进入状态   ← 未拍
- Screen: 开屏或今晚大海报全出血
- Key: 品牌收束，不当第一张

Slot 10: 先为下一场留一个倒数   ← 未拍，可暂缺
- Screen: 空状态 + 添加
- Key: CTA。没有社会证明就先不要硬拍「加入 N 万人」
```
