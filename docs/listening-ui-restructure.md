# 听 Tab UI 重构实施基线

状态：访谈决策及实施已获用户确认，实施中。原始需求的范围、可访问性、国际化、测试和验收条件继续适用；以下明确覆盖原需求中单张、约十二首热门歌集的规定。

## 2026-09-20 视觉舞台方向

- 「听」的视觉主角固定为 CD 播放机与当前唱片，优先级为：唱片 / 播放机 → 唱片驱动的环境光 → LCD / 运输控制 → 唱片柜 / Header。
- Phase 1 仅重新分配视觉重量：播放器约放大 15%，唱片柜收小，当前唱片色彩从播放器局部 halo 延伸到整个舞台；不改变任何 MusicKit、播放、熟悉度、浏览、手动取碟或机械换碟行为。
- Current Show 封面继续提供稳定的远景房间光；已装入唱片提供更靠近播放器的动态主光。播放时只增强已有光场，不创建独立 UI 状态机。
- 为保留现有实体拖放，Phase 1 暂时保留「艺人选择器 → 唱片柜 → 播放器」的交互邻接关系。后续唱片选择 drawer / 开盖换碟属于独立阶段，不在本阶段提前混入。
- 播放视觉必须继续以 transport / ListeningDisplayProjection 为事实来源；View 不重新推导授权、可播放能力或播放状态。

## 已确认的行为

- 页面结构仍为标题「听」→ 单行头像艺人选择器 → 唱片柜 → CD 播放器，但视觉重量改为播放器绝对主导；该结构仅在 Phase 1 为现有手动拖放暂时保留。
- 浏览范围明确区分全部和艺人身份；初始为全部，失效身份回退全部。浏览切换不改变播放、不主动滚动。
- 全部范围仅展示虚拟「热门合辑 01、02、03」，总共最多三张；首页直接展示全部，不再为热门合辑提供额外「查看全部」入口。
- 单艺人首页最多三张真实专辑，不凑数；超过三张时通过「查看全部」进入完整三列作品网格。
- 点击唱片只打开封套详情；可翻到背面查看曲目，点曲目通过自动装碟流程播放指定歌曲，真实播放成功后关闭详情。单纯浏览或翻面不改变播放。「装入播放机」保留原有重复装入语义。此项由 #162 更新。
- 首次进入无碟。主动装入另一张碟后，从第一轨自动播放。
- 对已装入的同一张碟再次执行装入：关闭详情，保留曲目、进度及播放状态；暂停或停止也不恢复播放。
- 浏览数据刷新不改变已装入唱片的曲目和顺序；用户主动装入另一版本时才采用新内容。
- Stop 停止并回到当前可见唱片第一轨，保留唱片。真实 Apple Music 唱片自然结束不循环、不跨碟，Previous/Next 也不跨真实唱片；BeforeShow 虚拟热门合辑是例外，01 → 02 → 03 在播放层属于同一个连续队列，可自然续播并通过 Previous/Next 跨卷。
- 自动装入和 OPEN 手动换碟共用现有 CDMechanism 的唱片及机械状态。

## 唱片柜与封面拟物进阶（吸收原型优点）

1. **封套 + 半抽出 CD 盘片（Sleeve + Peeking Disc）**：
   - 首页唱片柜卡片由 76×76pt 唱片封套与右侧露出的一截 68pt 镭射 CD 光盘组合（总宽约 94pt）。
   - 当该唱片被装入播放机后，右侧露出的光盘平滑隐藏，表达实体光盘已被取出装入播放机。
   - 专辑详情页顶部同样采用大尺寸半抽出实物陈列（136pt 封套 + 124pt 镭射光盘），增强收藏质感。
2. **唱片柜立体托梁（Rack Beam & Lip）**：
   - 唱片底部设立 4pt 高深暗立体导轨托梁与顶部 1pt 暖金边缘反光，赋予唱片稳固的物理着陆感。
   - 唱片柜标题行展示当前艺人/合辑名称，附带紧凑数量标签（如「12 首」或「4 张唱片」），右侧顺畅衔接「查看全部 >」。
3. **保持现有 Panasonic CD 播放机**：
   - 播放机身与开盖物理引擎继续复用现有高拟真 Panasonic 3D 模型与弹簧驱动，不采用简化的矢量外观。
   - 顶栏保持纯净大标题「听」，不添加额外现场胶囊或换碟浮层。

## 手动取碟交互（2026-09-08 已确认）

1. 首页横向唱片柜中，单击整张唱片卡继续打开专辑详情；只在长按封套右侧露出的 CD 约 0.3 秒后，从封套抽出 CD 并进入跟手拖动。长按封套本身不取碟。触发时提供一次轻触觉反馈，触发前不妨碍横向滚动。
2. 播放机无碟时，长按取碟同时自动开盖。即使用户在开盖动画结束前松手，只要落点命中托盘，这次放置仍然有效，CD 会在上盖打开后落入。
3. CD 拖到托盘并松手即完成装入；删除用户可见的「已卡紧 / 已松脱」中心轴状态及其额外点击。装入确认音在 CD 落到托盘中心并机械到位时播放。
4. 手动装入后上盖保持打开。用户手动合盖后仍需按播放键，不自动播放。
5. 从唱片柜取出的 CD 未命中托盘时自动回到原封套；若此次手势自动打开了上盖，上盖保持打开，方便立即重试。
6. 播放机已有 CD 时，长按其他唱片不取出新 CD、不自动换碟；以视觉反馈强调当前 CD，并提示「先取出当前 CD，并放回唱片柜」。
7. 删除当前 CD 的中心轴松脱步骤。开盖后可直接拖动当前 CD；松到唱片柜任意位置都会自动归回原封套，无需对准卡槽。
8. 「查看全部」仍是覆盖播放机的弹层，因此不提供跨层实体拖放；其中单击唱片进入详情，并保留「装入播放机」的自动换碟、合盖及播放快捷流程。
9. VoiceOver 为唱片提供「取出并放入播放机」自定义动作，自动完成无法通过拖动完成的位移；完成后仍保持上盖打开。
10. 不增加手势说明文字。首次出现可手动取出的唱片时，露出的 CD 只做一次轻微抽动以提示可交互；开启「减弱动态效果」时不播放这段提示动画。

## 热门合辑组装

1. 仅使用当前现场已确认艺人的 Apple Music topSongs；多艺人场景总共最多三张，每张最多 20 首，整体最多 60 首。曲源不足时自然少于该上限，不重复、不补入非 topSongs。
2. 多艺人选择采用「覆盖优先，再增加深度」：先让每个仍有可用 topSongs 的艺人贡献下一首，再进入下一轮；大型音乐节在曲源充足时形成约 40–60 首的连续预习集合。
3. 每张虚拟唱片内部将同一艺人的已选歌曲相邻排布，并保留该艺人的 Apple Music topSongs 原始顺序；不根据本地推测重新排序热门程度。
4. 全局按 songID 去重，保留第一次被选中的位置，不随机补歌。
5. 只有一个有效艺人时继续使用独立富内容规则：每张最多 10 首、最多三张，不套用多艺人 20 首分卷规则。
6. 三张虚拟唱片在 UI 中继续保持「热门合辑 01 / 02 / 03」身份，但播放层扁平为一个连续队列；从任意曲目开始后可跨卷继续，最终一首结束后正常停止且不循环。
7. 虚拟碟使用独立 presentation 和确定性本地封面，不伪造 Apple Music Album。

## 热门合辑与目录加载

1. 进入「听」的全部艺人范围时，runtime topSongs 是热门合辑的快速数据路径；热门合辑可用不等待所有艺人的完整 albums / singles / compilation albums。
2. runtime topSongs 保持内存态，不把它写成「完整艺人目录」，也不能替代熟悉度使用的完整去重 catalog。
3. 用户明确进入某位艺人的浏览范围后，才按现有刷新策略加载该艺人的完整目录，并继续按需加载该艺人的 browse-only 内容；不会因为浏览一位艺人而拉取其他艺人的完整目录。
4. 完整去重 catalog 的熟悉度语义保持不变；本次只改变完整目录的触发时机。大型音乐节性能仍须遵守 #194 的 MainActor 响应性与批量持久化约束。

## 已发现的实现边界

- ListeningRoomView 编排当前页面；优先拆分、重组现有组件，不保留平行主页。
- ListeningRoomCoordinator.filterArtist 目前会停止、重组并装入唱片，不能用作新的浏览选择动作。
- ArtistCatalogSnapshot.topSongIDs 已保存热门顺序，可用于合辑组装。
- 现有 preparation 唱片来自预习队列，不能直接重命名成热门合辑。
- ListeningDiscDetailView 的背面曲目通过协调层发送选曲意图，忙碌或不可播放时不可重复提交。
- 复用 CDMechanism 和 ListeningPlaybackController；播放冲突集中修改并测试，View 只发送 intent。

## 2026-09-26 空状态、唱片区稳定与播放器提示收敛

1. 「听」空状态与「当前 / 足迹」采用同一视觉骨架：80pt 圆形图标、hero title、body 说明、180×49 主按钮，以及一致的间距、颜色、圆角与 root header 节奏；听模块只保留自身图标与文案差异。
2. 空状态 CTA 采用统一状态规则：完全没有现场时三个主 Tab 都提供「添加现场」；已有现场但未选中当前现场时，「当前 / 听」提供「选择现场」，「足迹」继续保留与足迹语义一致的添加入口。
3. 顶部艺人 Tab 切换不得改变唱片区总高度。是否显示「唱片柜」入口只改变内容可见性，不参与 header 高度计算；单张唱片继续左对齐。
4. CD 机 LCD 独立承担歌名、艺人、轨道、播放/暂停状态与时间。CD 机下方不再重复这些信息，只保留固定高度的一行必要提示；需要恢复时可额外出现重试操作。
5. 回归测试必须覆盖「唱片柜」入口出现/消失时 shelf 实际高度一致，并用结构测试防止重新引入双 header 高度或 CD 机下方重复歌曲信息。
